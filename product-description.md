# Exercise Tracker

## Background
We believe that doing exercises every day is better than go to the gym 2-3 times a week.
We want an app where it very simple to count the number of reps you have been doing every day.

## Scenarios

### Register
As a user you can register using Facebook, Google or be anonymous where you simply select a username, password and a hint Q and Q to reset password

### Add new exercise
Add new exercise you want to count.
The exercise ui should suggest validated excercises, so if you start writing "push" it will show exercises containing the word.
If the user adds a new exercise then it need to be validated before other users can see it.

### Add a new day
Every day when you start then you press "New day" and your standard exercises will be available for that day to register repetitions.

### Add repetitions
1. Once you have done for example 10 pushups, simply press "Add reps" at the pushup exercise.
2. type number of reps
3. After submit the UI shows the accumulated number of reps for that day

### Statistics
As a user you should be able to see number of reps for a specific perios. for example this week, this month, this year, since ...

## Technology
The web app must be mobile first and must work offline. 
The wea app must be a Progressive Web App (PWA).
